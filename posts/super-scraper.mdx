## First issue
At first, I tried to use the `requests` library, but something went wrong cause the page seemed to be not fully loaded.
I investigated further and discovered that if a page uses JavaScript, we need to attend until all the code is executed so the page is fully loaded.

    How? Using [requests_html](https://requests.readthedocs.io/projects/requests-html/en/latest/) instead of [requests](https://requests.readthedocs.io/en/latest/).
    With this new library we can create the `get_page` method

```py title="spider.py"
def get_page(session: HTMLSession, url: str):
# Get the page
r = session.get(url)

# If page not found / errors occurred return None
if r.status_code != 200:
return None

# Wait page loading to get Javascript loaded elements
r.html.render(timeout=50000, keep_page=True)
return r.html
```

this function returns the HTML after waiting for the execution of JavaScript code.

this file will be passed as an argument at some functions to allow logging.

    Let's take a look at the `create_log` function.
```py title="files.py"
def create_log():
try:
# Create log folder if not exists
if not os.path.exists("./logs/"):
os.makedirs("./logs/")

# Get the current date that will be the name of the log
dt_string = datetime.now().strftime("%d_%m_%Y_%H_%M_%S")

file_name = f"./logs/{dt_string}"

# Create the md file
mdAcme = MdUtils(file_name=file_name)
print(f"Log {file_name} created")
return mdAcme.create_md_file()

except Exception as e:
print(e)
return None
```

We see the use of the `os` module to prevent bugs on different operating systems.
    We create the log folder if not exist already, and in it, we create the new log file.
    To name the file, we use the current date to prevent overlapping names.

# The Nmap
We said we want to collect information about the target system (IP, operating system, etc.).
Here Nmap comes in, but how can we use Nmap in our program?
    I found a library called [python3-nmap](https://pypi.org/project/python3-nmap/).
I installed the library using

    ```shell title="terminal"
pip install python3-nmap
```

and then implemented a function named `nmap_scan`.

```py title="scrapers.py"
def nmap_scan(url: str, log: MarkDownFile | None):
nmap = nmap3.Nmap()
log.append_end("# Target Information\n")
log.append_end("## Nmap Scan\n")
log.append_end("### Ports\n")
log.append_end(str(nmap.scan_top_ports(url)) + "\n\n")
log.append_end("### OS\n")
log.append_end(str(nmap.nmap_os_detection(url)) + "\n\n")
```

**It's clear that to use this script, you must have Nmap installed on your operating system**

Also, the OS scan requires root privileges, so this program needs to be executed with root privileges.

**OK, I joke the code above does not work.**

Yes, cause Nmap will not find the IP of the site automatically, so there are two options:
1. You insert the association between the site's URL and the relative IP in your DNS configuration manually
2. You get the IP of the site in the code and pass it to Nmap

Clearly, we chose the second option.
So let's see what we do
```py title="scrapers.py"
def nmap_scan(url: str, log: MarkDownFile | None):
url = url.replace("https://", "").replace("/", "")

ip_address = socket.gethostbyname(url)

(str(nmap.nmap_os_detection(ip_address)) + "\n\n")
```

As you can see we use the `socket` module to get the IP address from the host name.
The URL needs to be formatted in the `www.site.com` format or `gethostbyname` will throw an error.

    Now we can pass this IP to Nmap instead of the URL.

```py title="scrapers.py"
def files(session: HTMLSession, url: str, log: MarkDownFile | None):
	sitemap_req = session.get(f"{url}/sitemap.xml")
	robots_req = session.get(f"{url}/robots.txt")

	log.append_end("# Files\n")

	# If found print sitemap.xml content
	log.append_end("## Sitemap\n")
	if sitemap_req.status_code == 200:
	log.append_end(sitemap_req.content.decode() + "\n")
	else:
	log.append_end("sitemap.xml not found\n")

	# If found print robots.txt content
	log.append_end("## Robots\n")
	if robots_req.status_code == 200:
	log.append_end(robots_req.content.decode() + "\n")
	else:
	log.append_end("robots.txt not found\n")
```

```py title="scrapers.py"
def contacts(page: object, log: MarkDownFile | None):
```

```py title="scrapers.py"
	# Code
	...

	# Load the file with the list of socials name as a JSON
	with open('./lists/social.json', 'r') as social_file:
	social_networks = json.load(social_file)

	# Create a pattern for matching URLs
	pattern = '|'.join(re.escape(url) for url in social_networks.values())

	# Find all matches in the text
	matches = re.findall(pattern, text)

	# Get the social network names from the matches
	matched_social_networks = [name for name, url in social_networks.items() if url in matches]

	log.append_end("#### Socials\n")

	# Check if text in the page represents a social
	for social in matched_social_networks:
	log.append_end(f"- {social}\n")
```

this code works, but does not consider that the URL in the webpage could be found in various formats, for example, if in the page the URL is formatted as "https://github.com" the code will not find it cause in the JSON the URL is formatted like "https://www.github.com".

    So? We replace the format of the URL in the JSON file.

```json title="socials.json"

    "23snaps": "23snaps.com",
    "4chan": "4chan.org",
    "8tracks.com": "8tracks.com",
```
